This software package contains no FLEURS dataset rows or audio. It implements
schema validation and scoring for separately supplied, authorized local inputs.
The synthetic test fixtures are invented solely to exercise that schema; they
are not published examples, actual decoder receipts, or empirical model results.
The dataset license is not a license grant for this software.
