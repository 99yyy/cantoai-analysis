# investigations/

Human campaign folders. One folder per research question. Name the folder in `kebab-case` from the topic (`post-2025-jyutping-drop`), not from a task id.

This tree holds notes, exploratory scripts, and indexes that sit beside the measurement loop. It is not a second scoresheet.

Machine-gated artifacts stay in `tasks/TASK-N/` (briefs, SQL, `results.json` / `mine.json`, `RESULT.json`) and `review/TASK-N/` (auditor write-ups). Do not put declared numbers or `RESULT` only here.

A campaign folder does not replace a task. Tasks remain the unit of measurement.

Current campaigns: `post-2025-jyutping-drop/` (why published Jyutping agreement falls after 2024 on this channel). Index of record for that campaign, including TASK-6/7/8 closed and TASK-9 open, is `post-2025-jyutping-drop/README.md`.
